Task 1: Usability Problems with the Current Spreadsheet Method

Most Important Usability Dimension: Efficiency

Managing shared expenses requires quick updates, automatic calculations, and easy balance checks. The spreadsheet slows users down and forces manual work, so efficiency is the most important usability dimension.

Usability Problems Identified

  1. Manual calculations

    Dimension: Efficiency

    The spreadsheet does not calculate splits, totals, or balances. Users must do mental math, which slows them down and increases cognitive load.

  2. Formulas are easy to break
  3. Hard to understand

    Dimension: Learnability

    Columns are unclear, formulas are hidden, and there is no visual grouping. New users must guess how the sheet works.

  4. Personal and shared expenses are mixed

    Dimension: Learnability and Efficiency

    Neo's, Trinity's, and shared expenses appear in the same table. Users must mentally track which is which, causing confusion and slowing them down.

  5. No clear running balance

    Dimension: Efficiency

    Users cannot easily see who owes whom, how much, or why the balance changed. They must scroll and interpret rows manually.

  6. No search, filter, or sort

    Dimension: Efficiency

    Users cannot quickly find or organize expenses. Everything requires manual scanning.

  7. Becomes cluttered as more rows are added

    Dimension: Efficiency

    Large spreadsheets become dense and hard to read. Scrolling increases and readability decreases.

  8. No error prevention

    Dimension: Safety

    The sheet allows invalid inputs such as negative values, mismatched totals, and wrong percentages. Errors are easy to make and hard to detect.

  9. Excessive scrolling

    Dimension: Efficiency

    Users scroll to add entries, check balances, and view wide columns. This slows down the workflow.

  10. No visual hierarchy

    Dimension: Learnability

    Everything appears in one flat grid with no sections or summaries. Users struggle to understand the structure.

  11. No separation of input and output

    Dimension: Safety and Learnability

    Users cannot tell which cells they should edit and which contain formulas. This leads to accidental overwriting.

  12. Cognitive overload

    Dimension: Learnability

    Too many raw numbers and formulas create mental strain. There is no simplification or guidance.

How the App Fixes the Spreadsheet Usability Problems

  1. Removes manual calculations
    • Clear input fields for splits and payments
    • Future automation built into the layout

    Fixes: Efficiency

  2. Prevents breaking formulas
    • Users only enter data into safe form fields
    • No exposed formulas to overwrite

    Fixes: Safety

  3. Easier to understand
    • Sections for each part of the expense
    • Labels, headers, and spacing
    • Guided workflow

    Fixes: Learnability

  4. Separates personal and shared expenses
    • Radio buttons for Neo, Trinity, Shared, and Custom
    • No mixing in one table

    Fixes: Learnability and Efficiency

  5. Shows running balances clearly
    • Dashboard summary
    • Recent transactions list

    Fixes: Efficiency

  6. Adds search, filter, and sort controls
    • Dedicated controls on the Transactions page
    • Supports fast lookup and organization

    Fixes: Efficiency

  7. Provides a cleaner layout that scales
    • 40% centered container
    • Section spacing
    • Organized pages

    Fixes: Efficiency

  8. Reduces input errors
    • Number fields, radio buttons, and dropdowns
    • Clear separation of required and optional fields

    Fixes: Safety

  9. Reduces scrolling
    • Separate pages for Dashboard, Add Expense, and Transactions
    • Logical flow instead of one long sheet

    Fixes: Efficiency

  10. Adds visual hierarchy
    • Logo and title header
    • Menu bar
    • Section headers
    • Quick Actions

    Fixes: Learnability

  11. Separates input from output
    • Add Expense page for input
    • Dashboard and Transactions pages for output

    Fixes: Safety and Learnability

  12. Reduces cognitive overload
    • Simple layout
    • Clear grouping
    • Only relevant information per page

    Fixes: Learnability
